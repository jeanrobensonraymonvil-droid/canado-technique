Quiz — Chapitre 1

4 questions
Question 1 / 4
L'option DHCP 003 configure...
Option DHCP 003 = Default Router (passerelle par défaut). Les clients l'utilisent pour accéder aux réseaux au-delà de leur sous-réseau local. Option 006 = DNS. Option 015 = Suffixe de domaine DNS.
Question 2 / 4
Pourquoi autoriser (authorize) un serveur DHCP dans Active Directory ?
Dans un domaine AD, un serveur DHCP doit être autorisé pour fonctionner. Cela empêche des serveurs DHCP malveillants ou accidentels (rogue DHCP) de distribuer de mauvaises configurations IP aux clients.
Question 3 / 4
Pourquoi définir une durée de bail courte (2h) pour le Wi-Fi invité ?
Les visiteurs arrivent et repartent rapidement. Avec un bail de 8 jours, un visiteur qui part garde son IP réservée 8 jours = épuisement rapide de la plage. Un bail de 2h libère les IPs des visiteurs partis dans les 2 heures.
Question 4 / 4
La fonctionnalité DHCP Failover permet de...
DHCP Failover (Windows Server 2012+) réplique la base de données DHCP entre deux serveurs. Si l'un tombe en panne, l'autre continue à distribuer les IPs. Il existe deux modes: Hot Standby (un actif, un passif) et Load Balance (les deux actifs, répartition 50/50).

Quiz — Chapitre 2

4 questions
Question 1 / 4
Quel enregistrement DNS doit être créé pour permettre la réception d'emails vers @canado-technique.ht ?
L'enregistrement MX (Mail Exchanger) indique quel serveur accepte les emails pour un domaine. Sans MX, personne ne peut envoyer d'email à @canado-technique.ht. Le MX pointe vers le nom du serveur de messagerie (ex: mail.canado-technique.ht) qui a lui-même un enregistrement A.
Question 2 / 4
Un enregistrement CNAME est utilisé pour...
CNAME (Canonical Name) crée un alias d'un nom vers un autre nom. Exemple: ftp.canado-technique.ht CNAME www.canado-technique.ht signifie que ftp.canado-technique.ht résout vers la même IP que www. Utile pour simplifier la maintenance: changer l'IP de www suffit pour mettre à jour ftp aussi.
Question 3 / 4
Qu'est-ce qu'un "forwarder DNS" ?
Un forwarder est un serveur DNS externe (8.8.8.8, 1.1.1.1) vers lequel votre serveur DNS interne transmet les requêtes pour les noms qu'il ne connaît pas (ex: google.com). Sans forwarder, votre serveur DNS interne ne résout que les noms du domaine local.
Question 4 / 4
La commande nslookup sert à...
nslookup est l'outil de diagnostic DNS universel. nslookup google.com vérifie si le DNS résout google.com. nslookup -type=MX canado-technique.ht affiche les enregistrements MX. En cas de problème de navigation web, nslookup est le premier outil à utiliser.

🎬 Guide de production
1
DFS (Distributed File System) (3 min) — Namespace DFS pour unifier les partages (\\canado-technique.ht\data → accès transparent même si les données changent de serveur).
2
Créer un partage (4 min) — New Share Wizard, permissions de partage vs permissions NTFS. Règle: permissions de partage = Contrôle total pour les groupes; utiliser NTFS pour le contrôle fin.
3
Quotas de disque (3 min) — Limiter l'espace utilisé par département. File Server Resource Manager (FSRM).
4
VSS — Volume Shadow Copy (3 min) — Snapshots automatiques des fichiers pour la récupération en libre-service. Configurer les snapshots horaires.
5
Audit des accès (2 min) — Journaliser qui accède à quels fichiers. Audit policies.

3.1 Permissions NTFS vs permissions de partage — La règle fondamentale

TypeS'appliqueContrôleRecommandation
Permissions de partageAccès réseau uniquement (via UNC \\serveur\partage)Contrôle total / Modifier / LireDonner Contrôle total aux groupes concernés — laisser NTFS tout contrôler
Permissions NTFSAccès local ET réseauToutes les permissions NTFS (lecture, écriture, suppression, etc.)Configurer précisément par groupe ici
Permission effectiveIntersection des deuxLa plus restrictive des deux s'appliqueToujours vérifier les permissions effectives (onglet Avancé → Accès effectif)
⚠️ La règle des permissionsLes permissions effectives = la plus restrictive entre partage et NTFS. Si partage = Contrôle total et NTFS = Lecture seule → l'utilisateur ne peut que LIRE. Bonne pratique: partage = Contrôle total pour Tout le monde (ou les groupes concernés), puis contrôler finement avec NTFS.
📝

Quiz — Chapitre 3

4 questions
Question 1 / 4
Pourquoi recommande-t-on de mettre les permissions de partage à "Contrôle total" pour le groupe, puis de contrôler via NTFS ?
C'est la bonne pratique Microsoft: les permissions de partage ne s'appliquent qu'aux accès réseau, pas locaux. NTFS s'applique aux deux. En tout contrôler via NTFS, on a une politique cohérente accès local/réseau. Simplifier le partage évite les confusions.
Question 2 / 4
VSS (Volume Shadow Copy Service) permet aux utilisateurs de...
VSS crée des snapshots automatiques des fichiers (toutes les heures, tous les jours). Les utilisateurs peuvent cliquer droit → Restaurer les versions précédentes pour récupérer eux-mêmes un fichier supprimé ou écrasé par erreur. Réduit considérablement les appels au helpdesk.
Question 3 / 4
DFS (Distributed File System) Namespace sert à...
DFS Namespace crée un arbre de noms logique (\\canado-technique.ht\data) qui peut pointer vers des serveurs de fichiers physiques différents. Si on migre les données vers un nouveau serveur, on change juste la cible DFS — les utilisateurs continuent à utiliser le même chemin.
Question 4 / 4
Que journalise l'audit d'accès aux fichiers sur un serveur Windows ?
L'audit d'accès (configuré via GPO + propriétés du dossier → Sécurité → Audit) journalise chaque accès avec: utilisateur, heure, poste source, type d'opération. Essentiel pour la conformité et l'investigation d'incidents (qui a supprimé ce fichier ?)

Quiz — Chapitre 4

4 questions
Question 1 / 4
Pourquoi Microsoft 365 est-il recommandé pour la plupart des PME haïtiennes en 2025 ?
Microsoft 365 = emails + Teams + SharePoint + OneDrive hébergés dans le cloud Azure. Pas de serveur on-premise à maintenir, accessible depuis n'importe où même lors des coupures EDH (depuis le téléphone), mises à jour automatiques, et collaboration Microsoft Teams incluse.
Question 2 / 4
Un certificat SSL auto-signé est...
Un certificat auto-signé chiffre bien le trafic mais n'est pas signé par une Autorité de Certification (CA) reconnue. Les navigateurs affichent un avertissement "certificat non approuvé". Acceptable pour les sites internes (intranet) où on peut ajouter l'exception. Pour un site public: utiliser Let's Encrypt (gratuit et reconnu).
Question 3 / 4
Quelle commande Linux installe le serveur web Apache ?
sudo apt install apache2 installe Apache sur Ubuntu/Debian. Sur CentOS/RHEL: sudo yum install httpd. Après installation: sudo systemctl start apache2 → sudo systemctl enable apache2 → test: http://localhost dans un navigateur.
Question 4 / 4
Le port standard HTTPS est...
HTTPS utilise le port TCP 443. HTTP utilise le port 80. Un serveur web en production doit être accessible sur le port 443 (HTTPS) et rediriger automatiquement les connexions port 80 (HTTP) vers HTTPS.

Quiz — Chapitre 1

4 questions
Question 1 / 4
Pour configurer une interface sur un routeur Cisco, quel mode faut-il être ?
Pour configurer une interface (ip address, no shutdown), il faut être en mode Interface Config. Chemin: enable → configure terminal → interface FastEthernet0/0.
Question 2 / 4
Quelle commande Cisco affiche la configuration actuellement active en RAM ?
show running-config (ou sh run) affiche la configuration active en RAM. show startup-config affiche la configuration sauvegardée en NVRAM (qui sera chargée au prochain démarrage).
Question 3 / 4
Pourquoi la commande "copy running-config startup-config" est-elle critique ?
La running-config est en RAM (volatile). Au redémarrage, le routeur charge la startup-config (NVRAM, non volatile). Si on ne copie pas la running vers la startup, toutes les modifications disparaissent au redémarrage.
Question 4 / 4
La commande "enable secret motdepasse" est préférée à "enable password" car...
enable secret chiffre le mot de passe avec MD5 (ou SHA256 sur IOS modernes). enable password le stocke en clair dans la config (même avec service password-encryption, le chiffrement est faible). Utiliser toujours enable secret.

🎬 Guide de production
1
VLANs — Segmentation logique (5 min) — Pourquoi les VLANs. VLAN 10 = Direction, VLAN 20 = Comptabilité, VLAN 30 = Opérations. Isoler les trafics, améliorer la sécurité.
2
Configuration des ports (4 min) — Mode access (poste de travail) vs mode trunk (liens inter-switch ou switch-routeur). switchport mode access, switchport access vlan, switchport mode trunk.
3
Spanning Tree Protocol (3 min) — Prévient les boucles réseau. Rôles: Root Bridge, Designated Port, Blocked Port. RSTP (Rapid STP) = version moderne.
4
Port Security (3 min) — Limiter le nombre de MAC par port. Protéger contre les connexions non autorisées.

Quiz — Chapitre 2

4 questions
Question 1 / 4
Un port switch en mode "access" est configuré pour...
Un port en mode access appartient à un seul VLAN. Les trames sortant d'un port access sont non taguées (le poste de travail ne voit pas le tag VLAN). Les ports trunk transportent plusieurs VLANs avec des tags 802.1Q.
Question 2 / 4
Quel est le rôle du Spanning Tree Protocol (STP) ?
Sans STP, les trames broadcast créent des boucles infinies entre switches redondants (broadcast storm). STP élit un Root Bridge et bloque les ports redondants pour créer une topologie sans boucle. RSTP (Rapid STP) converge en quelques secondes vs 30-50s pour STP classique.
Question 3 / 4
La commande "show vlan brief" sur un switch Cisco permet de...
show vlan brief est LA commande de vérification VLAN sur un switch Cisco. Elle affiche: ID VLAN, nom, statut (active/suspended), et la liste des ports assignés à chaque VLAN. Indispensable pour valider la configuration.
Question 4 / 4
Pourquoi éviter d'utiliser le VLAN 1 pour le trafic utilisateur ?
Le VLAN 1 est le VLAN natif par défaut sur tous les switches Cisco. Il est potentiellement exploitable par des attaques VLAN hopping. Bonne pratique: utiliser des VLANs numérotés pour tout le trafic et changer le VLAN natif du trunk vers un VLAN non utilisé.

🎬 Guide de production
1
Configuration d'interface routeur (4 min) — interface Serial0/0/0, ip address X.X.X.X mask, no shutdown. Interface LAN (FastEthernet) vs WAN (Serial). Clock rate sur le DCE.
2
Routage statique (5 min) — ip route réseau_dest masque next_hop. Route par défaut: ip route 0.0.0.0 0.0.0.0 next_hop. Vérification: show ip route.
3
RIP v2 (4 min) — router rip, version 2, network X.X.X.X, no auto-summary. Simple à configurer, adapté aux petits réseaux.
4
OSPF (5 min) — router ospf 1, router-id, network X.X.X.X wildcard area 0. Plus scalable que RIP, converge plus vite, utilisé dans les vraies entreprises.

Quiz — Chapitre 3

4 questions
Question 1 / 4
Comment configurer une route par défaut sur un routeur Cisco ?
ip route 0.0.0.0 0.0.0.0 next-hop configure la route par défaut: "pour toute destination inconnue, envoie vers ce next-hop." C'est la route de dernier recours, utilisée pour la connexion internet (traffic non local vers le FAI).
Question 2 / 4
Quelle est la principale limitation de RIP v2 ?
La métrique de RIP est le nombre de sauts (routeurs traversés). Un réseau à 16 sauts ou plus est considéré comme inaccessible (métrique = infini = 16). Ce qui rend RIP inadapté aux grands réseaux. OSPF n'a pas cette limitation.
Question 3 / 4
La commande OSPF "network 192.168.1.0 0.0.0.255 area 0" signifie...
La commande network OSPF utilise un wildcard (inverse du masque). 0.0.0.255 = /24 (255 en binaire = 8 bits à 1 = 8 bits hôte). "area 0" = backbone OSPF. Cette commande annonce le réseau 192.168.1.0/24 dans le processus OSPF.
Question 4 / 4
Quelle commande Cisco affiche la table de routage complète ?
show ip route est LA commande fondamentale de vérification du routage. Elle affiche toutes les routes connues avec leur origine (C=connected, S=static, R=RIP, O=OSPF, D=EIGRP) et le next-hop. Si une route manque, les paquets vers cette destination seront droppés.

Quiz — Chapitre 4

4 questions
Question 1 / 4
NAT PAT (Port Address Translation) permet de...
NAT PAT (aussi appelé NAT overload) traduit plusieurs adresses privées vers une seule adresse publique en distinguant les sessions par le numéro de port. C'est le fonctionnement standard de tous les routeurs ADSL/fibre domestiques et la grande majorité des routeurs d'entreprise.
Question 2 / 4
Où placer une ACL étendue pour être le plus efficace ?
Les ACL étendues filtrent selon la source ET la destination. En les plaçant près de la source, on bloque le trafic le plus tôt possible, évitant qu'il traverse inutilement le réseau. Les ACL standard (filtrage IP source uniquement) se placent près de la destination.
Question 3 / 4
Quelle commande configure le routeur Cisco comme serveur DHCP pour le réseau 192.168.10.0/24 ?
ip dhcp pool NOM crée le pool DHCP. Ensuite: network 192.168.10.0 255.255.255.0 (plage), default-router 192.168.10.1 (passerelle), dns-server 8.8.8.8 (DNS), lease 7 (durée du bail en jours).
Question 4 / 4
La commande "show ip nat translations" affiche...
show ip nat translations montre les entrées actives dans la table de traduction NAT: inside local (IP privée:port), inside global (IP publique:port), outside local, outside global. Essentiel pour diagnostiquer des problèmes de NAT.

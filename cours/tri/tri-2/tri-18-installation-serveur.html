Quiz — Chapitre 1

4 questions
Question 1 / 4
Quelle est la principale différence entre un serveur et un PC de bureau ?
Un serveur est conçu pour la disponibilité et la fiabilité: alimentation double (si une tombe en panne, l'autre prend le relais), RAID pour la redondance des disques, ECC RAM qui corrige les erreurs mémoire. Un PC de bureau s'arrête, un serveur reste disponible.
Question 2 / 4
La virtualisation de serveurs permet de...
La virtualisation (VMware, Hyper-V, KVM) permet de créer N serveurs virtuels sur 1 serveur physique. Exemple: un serveur à 150 000 HTG peut héberger DC + DNS + DHCP + Fichiers = 4 serveurs pour le prix d'un.
Question 3 / 4
Dans le contexte haïtien, quel équipement est INDISPENSABLE dans une salle serveur ?
L'UPS (Uninterruptible Power Supply) protège les serveurs contre les coupures EDH. Il maintient l'alimentation le temps d'effectuer un arrêt propre ou de démarrer le générateur. Les arrêts brusques (coupures EDH directes) peuvent corrompre les données et endommager les disques.
Question 4 / 4
Quel type de serveur gère centralement les comptes utilisateurs et les stratégies de groupe ?
Le contrôleur de domaine (DC) avec Active Directory est le centre névralgique d'un réseau Windows. Il authentifie tous les utilisateurs, applique les stratégies de groupe (GPO), gère les mots de passe et les permissions. Sans DC, chaque PC gère ses propres comptes — impossible à administrer.

Quiz — Chapitre 2

4 questions
Question 1 / 4
Quelle édition de Windows Server est adaptée pour une PME haïtienne de 50 employés ?
Windows Server Standard est l'édition adaptée aux PME. Essentials est limité à 25 utilisateurs et 50 appareils — trop restrictif. Datacenter est pour les grandes infrastructures de virtualisation. Standard offre toutes les fonctionnalités nécessaires à une PME.
Question 2 / 4
Quelle taille de partition recommande-t-on pour le système Windows Server ?
80 GB minimum pour la partition système Windows Server. Windows Server + rôles + mises à jour + logs peuvent facilement consommer 40-60 GB. Avec 80 GB, on a de la marge. Les données (partages fichiers, BDD) doivent être sur une partition séparée — jamais sur C:.
Question 3 / 4
La convention de nommage "DC01" pour un serveur signifie...
DC = Domain Controller. La numérotation (01, 02) permet de distinguer les redondances. DC01 est le contrôleur de domaine principal, DC02 son réplica. Cette convention est universellement reconnue dans les équipes IT.
Question 4 / 4
Après l'installation de Windows Server, quelle est la première action recommandée ?
Les mises à jour de sécurité sont prioritaires sur un serveur. Un serveur Windows sans mises à jour est exposé à des failles connues et potentiellement exploitées. Toujours patcher avant de mettre le serveur en production.

🔑 La règle d'or AD: gérer les permissions par groupesNe jamais attribuer des permissions directement à un utilisateur. Toujours: créer un groupe, attribuer les permissions au groupe, ajouter les utilisateurs au groupe. Raison: si Marie remplace Jean, on retire Jean du groupe et on ajoute Marie — les permissions suivent automatiquement.

Quiz — Chapitre 3

4 questions
Question 1 / 4
Dans Active Directory, une OU (Unité Organisationnelle) est...
Une OU est un conteneur dans l'annuaire AD qui regroupe des objets (users, groupes, PC) pour faciliter l'administration et l'application de stratégies de groupe (GPO). Exemple: OU=Comptabilite contient tous les utilisateurs du département comptabilité.
Question 2 / 4
Pourquoi gérer les permissions via des groupes plutôt que directement par utilisateur ?
Gérer par groupes est fondamental en bonne pratique AD. Si 20 personnes ont les mêmes droits, créer 1 groupe et y mettre 20 personnes. Quand quelqu'un quitte ou rejoint, on le retire/ajoute du groupe — pas besoin de modifier 20 dossiers partagés.
Question 3 / 4
Quelle console Windows Server permet de créer des stratégies de groupe ?
GPMC (Group Policy Management Console) est l'outil pour créer, modifier et lier des GPO. Les GPO permettent de configurer des centaines de paramètres de sécurité et de bureau sur tous les postes du domaine simultanément.
Question 4 / 4
Un domaine Active Directory avec le suffixe ".local" signifie...
Le suffixe .local est réservé aux domaines AD internes (non publiés sur internet). Exemple: canado-technique.local est uniquement résolvable depuis l'intérieur du réseau. Sur internet, canado-technique.ht est le domaine public. Les deux sont distincts.

Quiz — Chapitre 4

4 questions
Question 1 / 4
Que signifie LTS dans "Ubuntu Server 22.04 LTS" ?
LTS = Long Term Support. Ubuntu LTS reçoit des mises à jour de sécurité pendant 5 ans (vs 9 mois pour les versions non-LTS). Pour un serveur de production, toujours utiliser une version LTS. Ubuntu 22.04 LTS est supporté jusqu'en 2027.
Question 2 / 4
Quelle commande systemctl vérifie si le service nginx est actif ?
systemctl status nginx affiche l'état complet du service: actif/inactif, PID, utilisation mémoire, et les dernières lignes de logs. Pour un test rapide: systemctl is-active nginx retourne "active" ou "inactive".
Question 3 / 4
Comment activer ufw (pare-feu) et autoriser uniquement SSH sur Ubuntu Server ?
ufw (Uncomplicated Firewall) est l'interface simplifiée d'iptables pour Ubuntu. Séquence: sudo ufw allow 22/tcp (autoriser SSH AVANT d'activer) → sudo ufw enable. Ne jamais activer ufw sans autoriser SSH d'abord sous peine de se bloquer l'accès à distance.
Question 4 / 4
Pourquoi installer Ubuntu Server sans interface graphique (mode texte) ?
Un serveur sans interface graphique (headless) utilise beaucoup moins de RAM (512MB vs 2GB+ avec GUI), libère le CPU pour les services, et a moins de logiciels installés = moins de vulnérabilités potentielles. L'administration se fait via SSH à distance.

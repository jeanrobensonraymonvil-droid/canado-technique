1.1 Concepts fondamentaux des bases de données

Une base de données relationnelle organise les données en tables liées entre elles par des relations. Elle garantit la cohérence, évite la duplication et permet des requêtes complexes.

ConceptDéfinitionExemple concret IT
TableEnsemble d'enregistrements du même typeTable "Équipements" avec tous les PCs du réseau
Champ (Colonne)Un attribut de la tableid_equipement, marque, modele, ip_adresse, statut
Enregistrement (Ligne)Une instance de la tablePC-001, Dell, OptiPlex 7090, 192.168.1.10, Actif
Clé primaire (PK)Identifiant unique de chaque ligneid_equipement — jamais NULL, jamais dupliqué
Clé étrangère (FK)Lien vers la clé primaire d'une autre tableid_technicien dans la table Tickets → Table Techniciens
IndexAccélère les recherches sur une colonneIndex sur ip_adresse pour retrouver vite un équipement
🗄️ Exemple BDD réseau haïtienUne PME de Pétion-Ville gère son parc informatique avec une BDD MySQL: Table Équipements (200 lignes), Table Techniciens (5 lignes), Table Tickets (1500 lignes), Table Interventions (800 lignes). En une requête SQL, le directeur IT voit en 0.2 secondes combien de tickets chaque technicien a traités ce mois.

Quiz — Chapitre 1

4 questions
Question 1 / 4
Qu'est-ce qu'une "clé primaire" dans une table de base de données ?
La clé primaire (Primary Key) identifie de façon unique chaque enregistrement. Elle est toujours NOT NULL et unique. Exemple: id_equipement auto-incrémenté garantit que chaque PC a un identifiant unique.
Question 2 / 4
Une "clé étrangère" sert à...
La clé étrangère (Foreign Key) référence la clé primaire d'une autre table, créant ainsi une relation. Exemple: id_technicien dans la table Tickets pointe vers id_technicien dans la table Techniciens.
Question 3 / 4
Quel SGBD gratuit est le plus utilisé dans les PME et ONG haïtiennes ?
MySQL (et sa variante communautaire MariaDB) est le SGBD open source le plus répandu mondialement. Gratuit, stable, bien documenté, il équipe la grande majorité des applications web et des systèmes de gestion des PME en Haïti.
Question 4 / 4
En quoi une base de données est-elle supérieure à un fichier Excel pour gérer un inventaire IT de 500 équipements ?
Une BDD offre: intégrité des données (pas de doublon), requêtes puissantes (SQL), accès multi-utilisateurs simultanés, sécurité par rôles, et performance sur de grandes volumétries. Excel devient instable et incohérent au-delà de quelques utilisateurs simultanés.

Quiz — Chapitre 2

4 questions
Question 1 / 4
Quel type SQL utiliser pour stocker l'adresse IP d'un équipement (ex: 192.168.1.10) ?
Une adresse IP est du texte (chiffres + points). VARCHAR(15) est le type correct (max 15 caractères pour une IPv4: 255.255.255.255). Alternativement, certains DBA stockent l'IP comme entier non signé pour faciliter le tri.
Question 2 / 4
Qu'est-ce qu'une relation "1 à N" dans une BDD ?
Une relation 1:N (one-to-many): un technicien peut avoir plusieurs tickets (N), mais chaque ticket est assigné à un seul technicien (1). C'est la relation la plus courante dans les BDD.
Question 3 / 4
La normalisation d'une BDD vise principalement à...
La normalisation élimine la redondance des données. Si le nom du technicien est stocké dans chaque ligne de ticket, une erreur de saisie crée des incohérences. Avec normalisation: le nom est dans la table Techniciens, et les tickets référencent l'ID du technicien.
Question 4 / 4
La commande SQL pour créer une table s'appelle...
CREATE TABLE est la commande DDL (Data Definition Language) pour créer une table. Exemple: CREATE TABLE techniciens (id INT AUTO_INCREMENT PRIMARY KEY, nom VARCHAR(100), email VARCHAR(150));

Quiz — Chapitre 3

4 questions
Question 1 / 4
Quelle requête SQL affiche tous les équipements actifs ?
SELECT * FROM equipements WHERE statut="Actif" est la syntaxe correcte. SELECT = lire. * = toutes les colonnes. FROM = depuis quelle table. WHERE = condition de filtrage.
Question 2 / 4
Pourquoi est-il dangereux d'exécuter UPDATE sans clause WHERE ?
Sans WHERE, UPDATE affecte toutes les lignes de la table. Exemple: UPDATE utilisateurs SET mot_de_passe="1234" sans WHERE change le mot de passe de TOUS les utilisateurs. Toujours tester avec SELECT avant d'exécuter un UPDATE/DELETE.
Question 3 / 4
Quelle commande SQL compte le nombre de tickets par technicien ?
COUNT(*) compte les lignes, GROUP BY regroupe par valeur unique de la colonne. Ensemble: SELECT id_tech, COUNT(*) as nb_tickets FROM tickets GROUP BY id_tech donne le nombre de tickets pour chaque technicien.
Question 4 / 4
INNER JOIN sert à...
INNER JOIN combine les lignes de deux tables qui ont une correspondance dans la condition ON. Exemple: INNER JOIN techniciens ON tickets.id_tech = techniciens.id retourne uniquement les tickets qui ont un technicien assigné (correspondance dans les deux tables).

Quiz — Chapitre 4

4 questions
Question 1 / 4
Pourquoi une application web ne doit-elle pas avoir le privilège DROP sur la BDD ?
Principe du moindre privilège: une application web n'a besoin que de SELECT, INSERT, UPDATE pour fonctionner. Si elle est compromise via injection SQL, un attaquant avec DROP TABLE pourrait détruire toute la BDD en une commande.
Question 2 / 4
Quelle commande crée une sauvegarde SQL d'une base de données MySQL ?
mysqldump crée un fichier SQL contenant les commandes CREATE TABLE et INSERT pour recréer et repeupler la BDD. C'est la méthode standard de sauvegarde MySQL. Le fichier peut être importé avec la commande mysql.
Question 3 / 4
Qu'est-ce qu'un "index" dans une table de BDD ?
Un index est une structure de données créée sur une colonne pour accélérer les recherches. Comme l'index d'un livre: au lieu de lire toutes les pages (scan complet), on va directement à la page (recherche indexée). Utile sur les colonnes utilisées dans les WHERE fréquents.
Question 4 / 4
La commande EXPLAIN SELECT sert à...
EXPLAIN SELECT montre le plan d'exécution: quels index sont utilisés, combien de lignes sont scannées, et si la requête est optimisée. Outil essentiel pour diagnostiquer les requêtes lentes.

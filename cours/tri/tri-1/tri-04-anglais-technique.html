Quiz — Chapitre 1

4 questions
Question 1 / 4
What does "bandwidth" mean in networking?
Bandwidth (bande passante) is the maximum data transfer capacity of a network link, measured in bps, Kbps, Mbps or Gbps. It is NOT the same as throughput (débit effectif), which is the actual data transferred.
Question 2 / 4
How do you correctly pronounce "router" in American English?
In American English (used in Cisco training), "router" is pronounced ROU-ter (rhymes with "shouter"). In British English it's ROO-ter. Since Cisco certification uses American English, learn the American pronunciation.
Question 3 / 4
Which command verb means "to check or examine" a network configuration?
"Verify" means to check or confirm something. In Cisco CLI, commands like "show ip route" or "show running-config" are used to verify configurations. "show" is the Cisco CLI verb for verification.
Question 4 / 4
What does "ACK" stand for in networking?
ACK stands for Acknowledgment. It's a signal sent to confirm receipt of data. In the TCP handshake: SYN → SYN-ACK → ACK. Understanding TCP acknowledgments is essential for CCNA certification.

Quiz — Chapitre 2

4 questions
Question 1 / 4
In technical documentation, what does the section "Troubleshooting" contain?
The "Troubleshooting" section contains error messages and their solutions. It's the first section to consult when something doesn't work. On Cisco docs, it's often called "Troubleshoot" or "Verify and Troubleshoot".
Question 2 / 4
What does the error message "Request timed out" mean?
"Request timed out" means the target machine didn't respond within the expected time. This could mean: wrong IP address, firewall blocking ICMP, machine is off, or network cable disconnected.
Question 3 / 4
In a Linux man page, where do you find practical usage examples?
The EXAMPLES section of a Linux man page contains practical usage examples. After reading SYNOPSIS (how to write the command) and OPTIONS (what each flag does), go to EXAMPLES to see real-world usage.
Question 4 / 4
A Cisco document says "Warning: This command erases all configuration." What should you do?
A "Warning" in Cisco documentation signals a risk of data loss or serious damage. You must always back up the configuration (copy running-config startup-config, or to a TFTP server) before executing such commands.

Quiz — Chapitre 3

4 questions
Question 1 / 4
In Cisco CLI, what does "!!!!! "mean after a ping command?
"!" after a ping means the packet was received successfully. 5 exclamation marks = 100% success rate. "." means timeout (no response), "U" means unreachable.
Question 2 / 4
What does "administratively down" mean for a Cisco interface?
"Administratively down" means the interface was manually disabled with the "shutdown" command. To re-enable it: interface FastEthernet0/0 → no shutdown. This is different from "line protocol is down" which indicates a physical issue.
Question 3 / 4
Which OSI layer is associated with "MAC addresses and frames"?
MAC addresses and frames operate at Layer 2 — the Data Link layer. Switches work at this layer. Layer 3 handles IP addresses and packets. This distinction is fundamental for Cisco CCNA.
Question 4 / 4
What mnemonic helps remember OSI layers from bottom to top (L1 to L7)?
"Please Do Not Throw Sausage Pizza Away" goes from L1 to L7: Physical, Data Link, Network, Transport, Session, Presentation, Application. The ascending version "All People..." goes from L7 down to L1.

Quiz — Chapitre 4

4 questions
Question 1 / 4
How would you say "Le problème a été résolu" in a professional IT context in English?
"The issue has been resolved" is the professional way to say the problem is fixed. "Issue" is preferred over "problem" in formal IT communication. "Resolved" is more professional than "fixed".
Question 2 / 4
What does "root cause" mean in a technical report?
"Root cause" means the fundamental, underlying cause of a problem. A good incident report must identify the root cause to prevent recurrence. Example: "Root cause: faulty network cable in Server Room B."
Question 3 / 4
Which phrase correctly describes having already tried something?
"I've already tried..." is essential in technical support to show the steps already taken. This avoids repeating the same steps and helps the support agent jump to the next level of troubleshooting.
Question 4 / 4
What does "SLA" stand for in IT service management?
SLA = Service Level Agreement. It's a contract defining the expected service level (uptime, response time, resolution time). Example: "Our SLA guarantees 99.9% uptime and a 4-hour response time for critical issues."

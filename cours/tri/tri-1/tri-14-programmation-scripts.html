Quel est le principal avantage d'automatiser une tâche répétitive avec un script ?
L'automatisation libère le technicien des tâches répétitives et à faible valeur ajoutée. Le temps économisé peut être réinvesti dans la résolution de problèmes complexes, l'amélioration de l'infrastructure, ou la formation.

Quel langage de script est le plus adapté pour automatiser des tâches sur des serveurs Linux ?

Quiz — Chapitre 2

4 questions
Question 1 / 4
Que signifie "#!/bin/bash" au début d'un script ?
#!/bin/bash est le "shebang" (hashbang). Il indique au système quel interpréteur utiliser pour exécuter ce script. /bin/bash est le chemin vers l'interpréteur Bash. Sans shebang, le script doit être explicitement appelé avec bash monscript.sh.
Question 2 / 4
Quelle commande rend un script Bash exécutable ?
chmod +x ajoute le droit d'exécution (x) sur le fichier. Après chmod +x monscript.sh, tu peux l'exécuter avec ./monscript.sh au lieu de bash monscript.sh.
Question 3 / 4
Dans un script Bash, comment afficher la valeur de la variable "NOM" ?
echo $NOM affiche la valeur de la variable NOM. Le signe $ est essentiel pour accéder à la valeur d'une variable en Bash. Sans $, echo NOM afficherait littéralement "NOM".
Question 4 / 4
Quelle structure Bash permet de répéter une action pour chaque fichier d'un répertoire ?
La boucle for en Bash: "for variable in liste; do commandes; done". L'utilisation de wildcards (*) permet d'itérer sur tous les fichiers correspondant au motif. Exemple: for pc in $(cat liste_pcs.txt); do ping -c1 $pc; done

Quiz — Chapitre 3

4 questions
Question 1 / 4
Qu'est-ce qu'un "pipeline" (|) dans PowerShell ?
Le pipeline | transmet l'objet de sortie d'une cmdlet directement à la cmdlet suivante. Exemple: Get-Process | Where-Object {$_.CPU -gt 50} | Stop-Process récupère les processus, filtre ceux > 50% CPU, et les arrête — tout en une ligne.
Question 2 / 4
Quelle cmdlet PowerShell teste la connectivité vers une IP sur un port spécifique ?
Test-NetConnection est plus puissante que ping: elle teste la connectivité TCP sur un port spécifique. Test-NetConnection -ComputerName 192.168.1.10 -Port 80 vérifie si le service web est accessible sur ce serveur.
Question 3 / 4
Comment exporter les résultats d'une commande PowerShell en fichier CSV ?
Export-CSV exporte les objets PowerShell en format CSV. L'option -NoTypeInformation évite d'ajouter une ligne de type au début du fichier. Idéal pour créer des rapports importables dans Excel.
Question 4 / 4
Quelle cmdlet PowerShell affiche les erreurs des journaux système Windows ?
Get-EventLog consulte les journaux Windows. -LogName System pour le journal système, -EntryType Error pour filtrer uniquement les erreurs. -Newest 20 limite aux 20 dernières. Équivalent de l'Observateur d'événements en ligne de commande.

Quiz — Chapitre 4

4 questions
Question 1 / 4
En cron Linux, que signifie "*/5" dans le champ des minutes ?
*/5 signifie "toutes les 5 minutes". L'astérisque représente "chaque", et /5 divise par 5. Donc */5 = 0, 5, 10, 15, 20... minutes. Très utilisé pour le monitoring fréquent.
Question 2 / 4
Dans PowerShell, l'option -WhatIf permet de...
-WhatIf est une option disponible sur de nombreuses cmdlets PowerShell destructives. Elle simule l'exécution et affiche ce qui AURAIT été fait sans faire aucun changement. Indispensable avant d'exécuter Remove-ADUser ou Format-Volume sur un serveur de production.
Question 3 / 4
Pourquoi est-il important d'enregistrer les logs des exécutions de scripts automatisés ?
Les logs de scripts permettent: 1) de voir si le script s'est exécuté, 2) d'identifier les erreurs, 3) d'auditer les actions automatiques (important pour la sécurité). Un script sans log est une boîte noire.
Question 4 / 4
En Bash, "set -x" en début de script active...
set -x active le mode trace/debug: chaque commande est affichée (avec un "+" devant) avant d'être exécutée. Idéal pour déboguer un script qui ne fonctionne pas comme prévu. set +x désactive le mode debug.

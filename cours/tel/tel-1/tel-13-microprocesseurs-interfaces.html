🎬 Guide de production
1
CPU — Unite Centrale (4 min) — ALU (Arithmetic Logic Unit): calculs. CU (Control Unit): orchestre les operations. Registres: memoires ultra-rapides internes au CPU. Accumulateur, compteur de programme (PC), pointeur de pile (SP).
2
Memoire et bus (4 min) — RAM (volatile, lecture/ecriture rapide). ROM/Flash (non volatile, programme). Bus donnees (8/16/32/64 bits), bus adresses (determine la memoire adressable), bus controle (lecture/ecriture/interruptions).
3
Microcontroleur vs microprocesseur (4 min) — µP: CPU seul (Intel, AMD). µC: CPU + RAM + Flash + GPIO + UART + ADC sur une seule puce (Arduino/ATmega328, PIC, STM32). Ideal pour systemes embarques.
4
Interruptions et DMA (3 min) — Interruption: signal externe qui arrete le CPU pour traiter un evenement urgent (reception donnee, bouton presse). DMA: transfert de donnees sans passer par le CPU = plus rapide.

Quiz — Chapitre 1

4 questions
Question 1 / 4
Difference principale entre RAM et ROM/Flash ?
RAM (Random Access Memory): memoire de travail, perd son contenu a la coupure de courant. Flash (type de ROM): memoire programme, conserve le code sans alimentation. Dans Arduino: 2KB RAM (variables) + 32KB Flash (programme).
Question 2 / 4
Un microcontroleur (comme Arduino) est prefere a un microprocesseur pour un systeme embarque car...
Systeme embarque = application specifique avec contraintes de taille, cout et consommation. Le µC tout-en-un (ATmega328 dans Arduino) remplace une carte mere complete. Utilise dans: thermostats, systemes d'alarme, equipements de mesure, automatismes.
Question 3 / 4
Une interruption dans un microprocesseur permet de...
Sans interruption: le CPU verifie en permanence (polling) si un evenement s'est produit = gaspillage CPU. Avec interruption: le CPU fait autre chose et est interrompu UNIQUEMENT quand l'evenement se produit. Plus efficace, plus reactif, economise de l'energie.
Question 4 / 4
Le DMA (Direct Memory Access) est utile pour...
Exemple: recevoir 1000 octets sur UART. Sans DMA: le CPU recoit chaque octet un par un (1000 interruptions). Avec DMA: le controleur DMA transfere les 1000 octets automatiquement en memoire, puis genere UNE SEULE interruption a la fin. Le CPU a ete libre pendant tout le transfert.

🎬 Guide de production
1
Carte Arduino Uno (4 min) — Microcontroleur ATmega328P. 14 GPIO numeriques (6 avec PWM). 6 entrees analogiques (ADC 10 bits). UART, I2C, SPI integres. Alimentation 5V ou USB. IDE Arduino gratuit.
2
Setup() et loop() (4 min) — setup(): execute une seule fois au demarrage. Configurer les broches (pinMode), initialiser la communication serie. loop(): boucle infinie = corps du programme. Lecture des capteurs, traitement, commande des actionneurs.
3
GPIO numerique et analogique (4 min) — digitalWrite(pin, HIGH/LOW): sortie numerique. digitalRead(pin): lecture numerique. analogRead(pin): lecture ADC 0-1023 (0-5V). analogWrite(pin, 0-255): PWM (sortie analogique simulee).
4
Communication serie (3 min) — Serial.begin(9600): initialise UART a 9600 bauds. Serial.println(): envoie donnees vers le moniteur serie. Utile pour le debogage. Wire.begin() pour I2C. SPI.begin() pour SPI.
📝

Quiz — Chapitre 2

4 questions
Question 1 / 4
Dans Arduino, setup() est execute...
setup() = initialisation unique. Contient: pinMode() pour configurer les broches, Serial.begin() pour la communication serie, Wire.begin() pour I2C, etc. Apres setup(), le programme entre dans loop() qui s'execute indefiniment.
Question 2 / 4
analogRead(A0) sur un Arduino Uno retourne une valeur entre...
Arduino Uno: ADC 10 bits. 0V -> 0. 5V -> 1023. 2.5V -> ~511. Conversion: tension = (analogRead * 5.0) / 1023. Pour lire un capteur de temperature LM35 (10mV/°C): T = (analogRead(A0) * 5.0 / 1023) / 0.010.
Question 3 / 4
analogWrite(pin, 128) sur une broche PWM Arduino genere...
analogWrite() genere du PWM (Pulse Width Modulation): rapport cyclique = valeur/255. 128/255 = 50%. La tension MOYENNE = 5V * 0.5 = 2.5V. Une LED a 50% du rapport cyclique = 50% de luminosite. Un moteur DC = 50% de vitesse.
Question 4 / 4
Serial.println("Tension: " + String(V) + "V") dans Arduino...
Serial.println() envoie des donnees via UART/USB vers le moniteur serie de l'IDE Arduino (ou n'importe quel terminal serie). Indispensable pour le debogage: afficher les valeurs lues des capteurs, l'etat des variables, les messages d'erreur. Ne necessite aucun composant additionnel.

3
Actionneurs (4 min) — LED: digitalWrite ou analogWrite. Moteur DC: transistor ou pont-H (L298N). Servomoteur: PWM (0-180 degres). Relais: commande une charge 220V depuis Arduino (transistor + diode flyback). Buzzer: ton(pin, frequence).
4
Interfaces I2C et SPI avec Arduino (3 min) — Afficheur LCD I2C (biblioth. LiquidCrystal_I2C). OLED SSD1306 (I2C). Lecteur carte SD (SPI). Module RTC DS3231 (heure en temps reel, I2C). Brancher, installer la bibliotheque, utiliser.

Quiz — Chapitre 3

4 questions
Question 1 / 4
Le capteur DHT22 mesure...
DHT22 (plus precis que DHT11): temperature -40 a 80°C (+/- 0.5°C) et humidite 0-100% (+/- 2-5%). Communication 1-Wire sur 3 fils (VCC, GND, DATA). Tres utilise dans les stations meteo embarquees et les systemes de surveillance environnementale (salles serveurs, sites telecom).
Question 2 / 4
Pour commander un relais 12V depuis une broche Arduino 5V, on utilise...
Broche Arduino: 5V, max 40mA. Relais 12V: 50-100mA de commande. Solution: transistor NPN (2N2222 ou BC337) en saturation. Broche Arduino -> R_base (1kOhm) -> Base transistor. Collecteur -> bobine relais (12V). Diode 1N4007 en antiparallele sur la bobine (protection lors de la coupure).
Question 3 / 4
Le module ESP8266 connecte a Arduino permet de...
ESP8266 = microcontroleur avec Wi-Fi integre. Connecte a Arduino via UART (TX/RX). Commandes AT ou programmation directe (ESP-01, ESP-12). Permet: envoyer les mesures vers ThingSpeak ou un serveur prive, creer une interface web de supervision, recevoir des alertes par email ou Telegram. Base de l'IoT low-cost.
Question 4 / 4
Un moniteur de tension secteur Arduino surveille la tension EDH. Si la tension chute sous 108V (10% en dessous de 120V), l'Arduino peut...
Application pratique en Haiti: la tension EDH est souvent instable (90-130V). Un systeme Arduino surveille la tension en continu (via transformateur + diviseur de tension + ADC), active une alerte si hors tolerance, peut couper l'alimentation d'equipements sensibles pour les proteger. Projet realiste et utile en contexte haiteien.

Quiz — Chapitre 4

4 questions
Question 1 / 4
Dans le projet "station meteo Arduino", la bibliotheque DHT.h est necessaire car...
Les bibliotheques Arduino sont des modules de code pre-ecrits pour des composants specifiques. DHT.h gere le timing precis (microseconde) du protocole DHT22. LiquidCrystal_I2C.h gere l'afficheur LCD via I2C. Ces bibliotheques permettent d'utiliser des composants complexes en quelques lignes de code.
Question 2 / 4
Pour mesurer la tension du reseau EDH avec Arduino, un transformateur abaisseur est necessaire car...
Chaine de mesure: 120V AC -> transformateur 12:1 -> 12V AC -> pont de Graetz + condensateur -> ~16V CC -> diviseur de tension (1:4) -> ~4V max -> ADC Arduino. Le diviseur de tension rapporte a la tension originale: V_120 = V_ADC * 4 * 1.414 * 12 / 5 (en simplifiant). Securite: utiliser un transformateur isole.
Question 3 / 4
Un testeur de composants Arduino peut mesurer une resistance inconnue via...
Montage: Vcc -> R_reference (10kOhm connue) -> noeud A -> R_inconnue -> GND. analogRead(A) donne V_A. R_inconnue = R_ref * (Vcc/V_A - 1). Pour V_A=2.5V, Vcc=5V, R_ref=10kOhm: R = 10k * (5/2.5 - 1) = 10k * 1 = 10kOhm. Precision depend de la tolerance de R_ref et de la precision de l'ADC 10 bits.
Question 4 / 4
L'IoT (Internet of Things) applique aux telecoms permet...
Exemple reel: un Arduino + ESP8266 sur un site distant mesure la temperature des equipements, la tension d'alimentation, l'etat du groupe electrogene. Si temperature > 50°C ou tension hors tolerance: alerte SMS ou email automatique au NOC. Intervention precoce avant la panne complete. Reduction des visites terrain = economie.

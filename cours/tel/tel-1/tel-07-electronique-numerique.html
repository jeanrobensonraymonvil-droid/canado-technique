1.1 Numérique contre analogique

Un circuit analogique traite un signal continu (toutes les valeurs). Un circuit numérique ne connaît que deux états : le 0 (niveau bas) et le 1 (niveau haut). C’est le monde du tout-ou-rien, base de l’informatique et des télécommunications modernes.

1.2 Les portes de base

NON (NOT / inverseur)l’entrée est à 0 (elle inverse)74LS05

1.3 Les portes combinées

PorteFonctionSortie à 1 si…
NON-ET (NAND)ET puis inversionau moins une entrée est à 0
NON-OU (NOR)OU puis inversiontoutes les entrées sont à 0
OU exclusif (XOR)différenceles entrées sont différentes
NON-OU exclusif (XNOR)égalitéles entrées sont identiques

Les portes NON-ET et NON-OU sont dites universelles : on peut réaliser n’importe quelle fonction logique uniquement avec elles.

📌 Bon à savoir
  • Un signal numérique n’a que deux états : 0 et 1.
  • Portes de base : ET (toutes à 1), OU (au moins une à 1), NON (inverse).
  • Portes combinées : NON-ET, NON-OU, OU exclusif (différence).
  • NON-ET et NON-OU sont des portes universelles.

🔑 Termes clés
Table de vérité — Liste exhaustive : sortie pour chaque combinaison d’entrées (2ⁿ lignes).
Expression logique — Écriture algébrique de la fonction (somme de produits).
Schéma logique — Représentation du circuit par les symboles des portes.

2.1 Construire une table de vérité

Pour n entrées, la table de vérité comporte 2ⁿ lignes (toutes les combinaisons possibles). On y indique la sortie attendue pour chacune. C’est l’outil de base pour décrire et vérifier un circuit numérique.

2.2 Écrire l’expression logique

À partir de la table, on écrit l’expression logique en faisant la somme (OU) des produits (ET) correspondant aux lignes où la sortie vaut 1. On obtient une équation booléenne qui décrit exactement la fonction.

2.3 Schéma ↔ expression

L’expression logique se traduit directement en schéma logique (chaque ET, OU, NON devient une porte) et réciproquement. Passer de l’un à l’autre est la compétence centrale pour concevoir ou dépanner un circuit.

📌 Bon à savoir
  • Une table de vérité a 2ⁿ lignes pour n entrées.
  • L’expression logique = somme (OU) de produits (ET) des lignes à 1.
  • Expression ↔ schéma logique : traduction directe.
  • La table de vérité décrit le comportement attendu d’un circuit.

🔑 Termes clés
Algèbre de Boole — Algèbre des variables à deux états (0 et 1).
Lois de De Morgan — Règles reliant ET, OU et l’inversion.
Diagramme de Karnaugh — Tableau visuel pour simplifier une expression logique.
Simplification — Réduire une fonction au minimum de portes.

3.1 L’algèbre de Boole

L’algèbre de Boole manipule des variables à deux états. Ses lois permettent de simplifier une expression et donc de réduire le nombre de portes :

LoiExemple
CommutativeA + B = B + A
AssociativeA + (B + C) = (A + B) + C
DistributiveA·(B + C) = A·B + A·C
IdentitésA + 0 = A · A·1 = A · A + A = A

3.2 Les lois de De Morgan

Les lois de De Morgan relient l’inversion aux portes ET et OU : l’inverse d’un produit est la somme des inverses, et l’inverse d’une somme est le produit des inverses. Elles permettent de transformer un montage et d’utiliser les portes universelles (NON-ET, NON-OU).

3.3 La méthode de Karnaugh

Le diagramme de Karnaugh est une table visuelle où l’on reporte les 1 de la fonction. On regroupe les cases adjacentes valant 1 par paquets de 1, 2, 4, 8… Chaque regroupement élimine une variable, ce qui donne directement l’expression simplifiée — plus rapide et plus sûr que l’algèbre pure.

📌 Bon à savoir
  • L’algèbre de Boole simplifie les expressions (commutative, associative, distributive).
  • De Morgan relie l’inversion aux portes ET et OU.
  • Le diagramme de Karnaugh regroupe les 1 adjacents (1, 2, 4, 8…).
  • Simplifier = moins de portes = circuit plus simple et moins cher.

🔑 Termes clés
Codeur — Circuit qui convertit 2ⁿ entrées en un code de n bits.
DCB (BCD) — Décimal codé binaire : chaque chiffre décimal sur 4 bits.
Décodeur — Circuit qui convertit un code de n bits en 2ⁿ sorties.
Afficheur 7 segments — Affichage piloté par un décodeur pour montrer un chiffre.
Comparateur — Circuit qui compare deux nombres binaires (A>B, A=B, A<B).

4.1 Le codeur

Un codeur transforme plusieurs entrées (2ⁿ) en un code compact de n bits. Le codeur de priorité traite l’entrée la plus prioritaire. Le codage DCB (décimal codé binaire) représente chaque chiffre décimal sur 4 bits. Un transcodeur convertit un code en un autre.

4.2 Le décodeur et l’afficheur 7 segments

Le décodeur fait l’inverse : il convertit un code de n bits en 2ⁿ sorties, dont une seule est active. Application majeure : le décodeur 7 segments, qui pilote un afficheur pour montrer un chiffre à partir de son code DCB.

4.3 Le comparateur numérique

Le comparateur compare deux nombres binaires A et B et fournit trois sorties : A > B, A = B et A < B. Il est à la base des décisions dans les systèmes numériques.

📌 Bon à savoir
  • Le codeur : 2ⁿ entrées → n bits ; le DCB code chaque chiffre sur 4 bits.
  • Le décodeur : n bits → 2ⁿ sorties (une seule active).
  • Le décodeur 7 segments pilote l’afficheur.
  • Le comparateur donne A>B, A=B, A<B.

🔑 Termes clés
Multiplexeur (MUX) — Aiguille plusieurs entrées vers une seule sortie, selon une adresse.
Démultiplexeur (DEMUX) — Aiguille une entrée vers plusieurs sorties, selon une adresse.
Lignes d’adresse (sélection) — Bits qui choisissent la voie active.
Multiplexage — Partage d’une voie commune entre plusieurs signaux.

5.1 Le multiplexeur

Un multiplexeur (MUX) possède plusieurs entrées et une seule sortie : des lignes d’adresse choisissent laquelle des entrées est dirigée vers la sortie. C’est un « sélecteur » de données, omniprésent en télécommunications pour faire passer plusieurs signaux sur une même voie.

5.2 Le démultiplexeur

Le démultiplexeur (DEMUX) fait l’opération inverse : une seule entrée est aiguillée vers l’une de plusieurs sorties, choisie par les lignes d’adresse. Il « distribue » le signal reçu.

5.3 MUX, DEMUX et synchronisation

En transmission, un MUX à l’émission et un DEMUX à la réception travaillent ensemble : les mêmes adresses doivent être présentées au même rythme. Cette synchronisation garantit que chaque donnée arrive sur la bonne voie de sortie.

📌 Bon à savoir
  • Le MUX : plusieurs entrées → une sortie (sélection par adresse).
  • Le DEMUX : une entrée → plusieurs sorties.
  • Les lignes d’adresse choisissent la voie active.
  • MUX + DEMUX doivent être synchronisés pour transmettre correctement.

🔑 Termes clés
Bascule (flip-flop) — Circuit séquentiel qui mémorise un bit (0 ou 1).
Bascule RS — Bascule élémentaire à deux entrées Set et Reset.
Horloge (clock) — Signal qui rythme une bascule synchrone.
Bascule D — Mémorise l’état de l’entrée D au coup d’horloge.
Bascule JK — Bascule universelle, sans état interdit.

6.1 Du combinatoire au séquentiel

Jusqu’ici, la sortie ne dépendait que des entrées (circuit combinatoire). Une bascule ajoute la mémoire : sa sortie dépend aussi de son état précédent. C’est la brique de base des circuits séquentiels.

6.2 Bascule RS, asynchrone et synchrone

La bascule élémentaire RS se réalise avec deux portes NON-OU (ou NON-ET) bouclées. S (Set) met la sortie à 1, R (Reset) la met à 0. Une bascule asynchrone réagit immédiatement ; une bascule synchrone ne change qu’au rythme d’un signal d’horloge.

6.3 Les bascules D et JK

BasculeComportement
Drecopie l’entrée D à chaque coup d’horloge (mémoire 1 bit)
JKuniverselle : Set, Reset, mémoire et bascule (toggle), sans état interdit

La bascule JK est la plus complète : elle élimine l’état interdit de la RS et sert de base aux compteurs.

📌 Bon à savoir
  • Une bascule mémorise un bit : c’est la base du séquentiel.
  • RS : S met à 1, R met à 0 (deux portes NON-OU bouclées).
  • Synchrone = commandée par une horloge.
  • D recopie l’entrée ; JK est universelle (sans état interdit).

🔑 Termes clés
Registre — Ensemble de bascules mémorisant un mot binaire de plusieurs bits.
Registre à décalage — Registre qui déplace ses bits d’une case à chaque coup d’horloge.
Mémoire — Circuit qui stocke des mots binaires, repérés par une adresse.
ROM — Mémoire morte : lecture seule, non volatile (garde l’information hors tension).
RAM — Mémoire vive : lecture et écriture, volatile (perd l’information hors tension).

7.1 Du bit au mot : le registre

Une bascule mémorise un bit. En groupant n bascules, on obtient un registre qui mémorise un mot de n bits (par exemple 8 bits = un octet). Le registre est l’unité de stockage de base d’un système numérique.

7.2 Le registre à décalage et la conversion série ↔ parallèle

Un registre à décalage déplace ses bits d’une position à chaque coup d’horloge. Il réalise la conversion série ↔ parallèle : en télécommunications, l’information circule souvent bit par bit (série) sur un seul fil ; le registre la reconstitue en mot (parallèle) à la réception, et inversement à l’émission.

7.3 Les circuits de mémoire : ROM et RAM

MémoireAccèsVolatilitéUsage
ROMlecture seulenon volatileprogramme figé, table de conversion
RAMlecture / écriturevolatiledonnées de travail, variables

Une mémoire est organisée en adresses (où) et données (quoi) : le bus d’adresse désigne l’emplacement, le bus de données transporte le mot. Sa capacité = nombre de mots × bits par mot.

📌 Bon à savoir
  • Un registre = groupe de bascules mémorisant un mot de n bits.
  • Le registre à décalage convertit série ↔ parallèle (clé en transmission).
  • ROM : lecture seule, non volatile ; RAM : lecture/écriture, volatile.
  • Une mémoire se repère par une adresse ; capacité = mots × bits.

Compteur — Circuit de bascules qui compte les impulsions d’horloge.
Division de fréquence — Chaque bascule divise la fréquence par 2.
Modulo — Nombre d’états d’un compteur (un compteur modulo N divise par N).

7.1 Compteurs et division de fréquence

En chaînant des bascules, on obtient un compteur : il compte les impulsions d’horloge. Chaque bascule divise la fréquence par 2 ; un compteur sert donc aussi de diviseur de fréquence. Un décompteur compte à rebours.

7.2 Modulo et cascade

Le modulo d’un compteur est son nombre d’états : un compteur modulo N compte de 0 à N−1 puis recommence, et divise la fréquence par N. En plaçant plusieurs compteurs en cascade, on étend la capacité de comptage.

7.3 Les convertisseurs CAN et CNA

ConvertisseurSensÉtapes / principe
CAN (ADC)analogique → numériqueéchantillonnage puis quantification (valeurs discrètes)
CNA (DAC)numérique → analogiquereconstruit une tension (réseau de résistances + ampli op)

Ces convertisseurs sont le pont entre le monde analogique (TEL-05) et le monde numérique : indispensables dès qu’un signal réel doit être traité par un circuit logique, et inversement.

📌 Bon à savoir
  • Un compteur compte les impulsions ; chaque bascule divise la fréquence par 2.
  • Un compteur modulo N divise la fréquence par N.
  • La mise en cascade étend la capacité de comptage.
  • CAN : analogique→numérique (quantification) ; CNA : numérique→analogique.

  • MUX/DEMUX — sélection par adresse ; synchronisation émission/réception.
  • Séquentiel — bascules RS/D/JK (mémoire, horloge) ; compteurs (modulo N, division par 2) ; CAN/CNA.
  • Registres & mémoires — registre = groupe de bascules (mot) ; registre à décalage (conversion série ↔ parallèle) ; ROM (non volatile) et RAM (lecture/écriture).
